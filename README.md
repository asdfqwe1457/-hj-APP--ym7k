灵活用工APP的功能模块全景——从岗位发布到薪酬结算的完整业务链路
一套完整的灵活用工APP系统，其功能架构围绕“用工企业—平台运营方—灵活就业人员”三层角色展开，覆盖从岗位发布到薪酬结算的完整业务闭环。

用工企业端（客户管理端）是系统的核心功能入口。企业用户需要完成实名认证和资质审核后方可发布岗位。核心功能包括：添加灵活用工人员（支持手动导入和Excel导入，导入前有草稿箱功能方便预审核）、创建劳动岗位（不同岗位对应不同的开票类目）、将劳动者与岗位进行关联（支持手动添加和身份证号批量添加）、创建工资单（明细支持手动添加、Excel导入、从岗位一键导入）。平台充值功能支持公对公银行转账无人值守充值和线下转账后管理员手动充值两种方式。

灵活就业人员端（劳动者端）的设计注重便捷性和权益保障。劳动者通过短信链接登录H5页面进行在线签约，签约通过e签宝等第三方平台完成要素认证。核心功能包括：查看待签约和已签约的合同、查看工资发放记录、管理个人资料等。在零工招聘场景中，劳动者端还需要支持简历发布、岗位浏览、在线投递、一对一沟通等功能。部分系统集成了在线考勤打卡能力，个人在同意申请或企业在同意申请后，需在规定时间和位置进行考勤打卡，打卡完成后由企业确认或提出异议。

平台管理端是系统运营的中枢。管理员通过后台完成分包商创建（需在数据库中直接创建并配置第三方平台参数）、代理商添加与分润比例设置、客户管理（普通客户、免签客户、API直连客户三种类型）、平台收益观察以及客户充值、提现、发票等业务处理。代理商拥有独立的管理后台，可添加客户、观察收益和进行余额提现。

从技术实现角度看，各模块之间存在紧密的数据联动关系。工资发放需要关联劳动者签约状态、岗位信息和平台余额，只有当客户余额不低于实际扣除金额时才可成功发放。这种数据联动要求系统在订单模型中设计清晰的状态流转规则。
